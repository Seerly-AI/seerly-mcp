# get_latest_brand_report: Latest Brand Report

Read-only.

The latest monthly Brand Report as text: headline, summary, section callouts, roadmap and next steps, with its date. A ready-made narrative for a pitch; pair it with get_brand_snapshot for current numbers.

## Arguments

| Argument | Type | Required | Description |
|---|---|---|---|
| `project` | string | yes | Which Seerly project: its domain (e.g. acme.com), shortId or id, as listed by list_projects. |
