# rank_publications: Rank publications

Read-only.

Which publications are worth pitching or paying for, in one call. Every site AI engines cite, every site linking to competitors and every PR Media target is first classified with Seerly's own source classification; only real publications get a verdict (worth_it, maybe or skip) with the reasons: AI answers citing it, whether it cites competitors and never the brand, gap topics it wins, domain rank, spam score, and the route in and cost of each researched placement. A paid placement is never worth_it when its cost is unknown or far above the other quotes. Forums, social networks, review sites, marketplaces and other non-publications are listed separately with what to do there instead. Quote the reasons; do not upgrade a verdict.

## Arguments

| Argument | Type | Required | Description |
|---|---|---|---|
| `project` | string | yes | Which Seerly project: its domain (e.g. acme.com), shortId or id, as listed by list_projects. |
